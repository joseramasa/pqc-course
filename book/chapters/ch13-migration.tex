\chapter{Migration Strategies}
\label{ch:migration}

\abstract*{The post-quantum transition is not merely an algorithm swap---it requires rethinking protocols, infrastructure, and organizational processes. This chapter provides a practical framework for migrating to post-quantum cryptography, covering hybrid deployment modes, protocol updates, and real-world case studies from TLS, code signing, and blockchain.}
